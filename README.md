# 🎥 YouTube UI Clone

A fully responsive **YouTube UI Clone** built using **React.js** and **Tailwind CSS**.  
The project replicates the modern design of YouTube’s homepage and video watch page — focusing on **clean UI**, **component reusability**, and **responsive design**.

---

## 🚀 Features

-  Modern, responsive layout similar to YouTube  
-  Sidebar and top navigation bar  
-  Video cards with thumbnails, titles, and channel info  
-  Watch page with recommended video section  
-  Built using **Tailwind CSS** for fast and clean styling  

---

## 🛠️ Tech Stack

⚛️ React JS	          : Frontend  <br>
🟣 Redux Toolkit	    : State management <br>
🌐 YouTube API        : v3	Real video data <br>
🎨 Tailwind CSS	      : Styling <br>
🚏 React Router DOM    :	Navigation <br>
